Local save policy:

- Treat questforge.json and game-state.json as canonical.
- Save after meaningful changes to fiction, mechanics, inventory, clocks, clues, checkpoints, or session logs.
- Never silently overwrite a newer save or newer remote copy.
- Keep checkpoints, journal files, and session logs inside the active campaign root.
- Prefer local files first, then optional export or sync adapters.
- Write manifests and summary files last when exporting.
- Preserve hidden GM notes from player-facing summaries.
- If a save is partial, say so clearly instead of implying success.
