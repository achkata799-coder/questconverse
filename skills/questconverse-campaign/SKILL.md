# QuestConverse Campaign

Use this skill for stateful campaign work.

## Handle with care

- campaign root and file layout
- NPC attitudes and relationships
- faction pressure and clocks
- clue trails and evidence
- session summaries and continuity
- player journal and scene notes
- hidden GM notes separate from player-facing text

## Best practice

- Update only the files that changed.
- Preserve current objectives, known clues, and open threads.
- Write compact state diffs instead of rewriting the whole campaign.
- Keep the player journal spoiler-free.
- Keep hidden GM notes in the dm/ folder or other hidden state files.
- Make campaign state recoverable from files, not only chat memory.
