# QuestConverse Rules

Use this skill whenever the game needs a ruling.

## Principles

- Make uncertainty visible.
- Show the reason for a check, the modifier, and the result.
- Keep combat state explicit: HP, conditions, order, resources, and consequences.
- Prefer simple rulings that keep play moving.
- If a rule is unclear, make the least disruptive call and continue.
- Resolve failures forward instead of stalling.

## Good outputs

- visible dice and totals
- short rules explanation
- combat state update
- what changed in the campaign files
