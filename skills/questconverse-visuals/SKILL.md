# QuestConverse Visuals

Use this skill for optional media work.

## Use when

- a scene image would improve clarity
- a map, item card, or portrait is helpful
- recurring visual continuity matters
- a user asks for a media refresh or export

## Rules

- Media must never block the game.
- Keep the visual canon aligned with the campaign state.
- Prefer a single useful image over many redundant ones.
- If media tools are unavailable, continue the session without them.
- Store visual prompts, references, and exports under `images/` when used.

## Good outputs

- scene prompt
- image request
- visual continuity note
- media status summary
